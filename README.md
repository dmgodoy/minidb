# minidb

An educational project to build a distributed key-value database from scratch in Java.

The first milestone is a single-node, in-memory key-value store exposed over HTTP
using the JDK's built-in `HttpServer` (no frameworks).

## Requirements

- Java 25
- Maven 3.9+

## Build

```sh
mvn clean package
```

## Test

```sh
mvn clean test
```
